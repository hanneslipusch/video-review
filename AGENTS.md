# video-review

This repo is public: anyone can read every commit, PR, issue and comment.

- Write for a stranger who has not seen your conversation. Describe a change by what it does, linking only to this repo and public pages.
- Examples and eval data are invented (the todo app, Wikipedia). Cases from real projects stay in the gitignored `evals-private/`, and so do their results.
- Before pushing or editing a PR, reread the diff and the text as that stranger.
- `bun run check` and `bun run test` pass before every push. `video-review build --help` gives the input format.
- A PR body says what changed, how you checked it, and what you did not.
